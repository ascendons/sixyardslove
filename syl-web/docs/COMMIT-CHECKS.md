# Commit checks

Updated by `scripts/commit.sh`. Run: `./scripts/commit.sh "your message"` or `npm run commit -- "your message"`

- **Build:** `npm run build`
- **Test:** `npm run test`
- **Format:** `npm run format` (Prettier)
- **Lint:** `npm run lint`
- **Audit:** `npm audit` (vulnerabilities block commit)
